# Security policy

Please report vulnerabilities privately to the repository maintainers rather
than opening a public issue. Include the affected version, Minecraft/NeoForge
versions, reproduction steps, and any relevant logs or packet traces.

Dashboard actions are intentionally server-authoritative: ownership, entity
identity, dimension, registry IDs, numeric bounds, and configuration revisions
are validated on the server. Reports involving bypasses of those checks,
cross-owner control, item duplication, ticket leaks, or unsafe block
modification are high priority.
